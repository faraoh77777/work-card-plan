# 똑씀이(구 공제플랜) — 카드 사용·연말정산 카드공제·가계부 목업

## 실행
index.html 파일을 Chrome 또는 Edge에서 엽니다. 별도 설치나 빌드가 필요 없습니다.
파일 직접 열기 환경에서 저장이 제한되면 VS Code Live Server 등 정적 서버로 실행하세요.

## 앱으로 설치(v1.5, 휴대폰·PC)
https 주소(예: GitHub Pages)에 올리면 휴대폰과 PC에서 앱처럼 설치할 수 있습니다.
- 안드로이드 Chrome: 메뉴 ⋮ → "홈 화면에 추가" 또는 "앱 설치"
- 아이폰 Safari: 공유 버튼 → "홈 화면에 추가"
- PC Chrome·Edge: 주소창 오른쪽 설치 아이콘 → 설치(시작 메뉴·바탕화면에 생김)
설치하면 인터넷이 없어도 열립니다(서비스워커 `sw.js`가 화면 사본을 보관하고, 인터넷이 되면 항상 새 화면을 받음). 단, .xlsx·.xls 불러오기는 SheetJS를 인터넷에서 받으므로 인터넷이 필요합니다.
사용내역은 기기마다 따로 저장됩니다(휴대폰과 PC가 자동으로 맞춰지지 않음).
파일을 바꿔 배포할 때는 `sw.js`의 `SW_VERSION`을 올립니다. 파일 직접 열기(file://)와 아티팩트에서는 서비스워커를 등록하지 않고 기존처럼 동작합니다.

## 포함 기능
- 목업의 네이비·민트 디자인, 모바일/PC 반응형 레이아웃
- 홈 / 사용내역 / 공제현황 / 설정 화면 전환
- 날짜·사용처·금액·결제수단·사용구분 입력 및 삭제
- 연도 변경, 월 이동, 결제수단 필터
- 실제 입력 데이터에 따른 연간/월간 합계 및 결제수단 비중
- 총급여 입력, 브라우저 localStorage 저장, JSON 백업 다운로드
- 최초 실행 시 2026년 샘플 내역 표시
- (v1.1) 중복공제 자동 집계: 사용구분 의료비·교복·취학전 학원비 내역을 모아 카드 소득공제와 의료비·교육비 세액공제를 함께 받을 수 있는 금액으로 표시(사용내역에 "중복공제" 표시)
- (v1.1) 현금영수증 국세청 확인: 홈택스 링크와 조회 메뉴 경로 안내, 현금영수증 내역마다 "국세청 확인" 표시(저장됨), 미확인 건수·금액 표시
- (v1.2) 카드 소득공제 실계산: 총급여와 입력 내역으로 최저사용액(총급여 25%) 달성률, 예상 소득공제액(기본+추가), 기본/추가 한도 진행 막대, 결제수단·사용처별 공제액을 계산. 순수 함수 `computeCardDeduction()`(별도 `<script>` 블록)은 work-tax-planner `engine.js`의 `computeCard`와 `rules/2025.js`를 옮긴 것으로, 같은 입력 507건에서 결과가 일치함을 확인
- (v1.3) 공제 제외 사용구분: 입력 폼 사용구분에 "공제 제외" 묶음(세금·공과금, 보험료, 통신비, 아파트관리비, 대출 상환, 대학등록금, 상품권, 면세점, 해외사용, 신차 구입, 월세(세액공제분)) 추가. 이 내역은 사용액 합계에는 들어가고 카드 소득공제 계산에서는 빠짐(`cardBucket()`이 null 반환, work-tax-planner `rules/2025.js` excludedCategories·engine EXCLUDED와 같은 처리). 공제현황에 제외 금액, 사용내역에 "공제 제외" 표시
- (v1.4) 카드사 엑셀 불러오기: 홈 "카드사 엑셀 불러오기"·사용내역 "엑셀 불러오기" 버튼으로 카드사 홈페이지에서 받은 이용내역 파일(.xlsx·.xls·XML 형식 엑셀·HTML 표 형식 .xls·CSV/탭 구분, UTF-8·EUC-KR·UTF-16)을 읽음. 카드사별 서식 대신 칸 이름(이용일자·승인일자·거래일시 / 가맹점명·이용하신 곳 / 이용금액·승인금액 등)으로 칸을 찾고, 위쪽 제목 줄·두 줄 칸 이름·합계 줄을 처리. 칸 이름을 못 찾으면 줄·칸을 직접 고르는 화면. 저장 전 확인 화면에서 저장 여부·결제수단·사용구분 수정. 카드 종류 칸에 "체크"가 있으면 체크카드, 없으면 화면에서 고른 결제수단. 사용구분은 가맹점 이름으로 자동 분류(work-tax-planner cardparse.js 규칙 이식, 공제 제외·대중교통·문화비·전통시장, 해외 표시·외화 통화는 해외사용). 취소(음수·"취소" 표시)는 (v1.6.3부터) 음수 금액 그대로 저장해 원거래와 상계(짝은 확인 화면에 표시만). 같은 파일을 다시 불러오면 이미 있는 내역은 건너뜀(내역마다 importKey 저장). 순수 함수 `parseCardSheet()`는 별도 `<script>` 블록
- (v1.5) 앱 설치(PWA)·JSON 백업 복원: 설정 "JSON 백업 복원(합치기)"로 다른 기기에서 받은 백업 파일의 새 내역만 추가(휴대폰↔PC 옮기기용)
- (v1.6) 카드사별 사용내역: 메뉴 "카드사별"에서 연간·월별로 카드사별 사용액·건수·비중(신용/체크/공제 제외 금액)을 보고, 카드사를 누르면 월별 사용액·사용구분별 합계·내역 목록을 봄. 내역에 선택 항목 `card`(카드사 이름) 추가: 직접 입력 폼에서 고르거나 입력, 엑셀 불러오기에서는 파일 이름과 칸 이름 위 제목 줄에서 카드사를 찾아 확인 화면에 채움(가맹점 이름은 보지 않음, 고칠 수 있음). 현금영수증은 카드사 없이 "현금영수증"으로, 카드사가 없는 내역은 "카드사 미지정"으로 묶고 상세 화면에서 줄별·일괄 지정. 순수 함수 `summarizeByCard()`·`guessCardIssuer()`. 카드사별 공제액은 나누지 않음(최저사용액은 전체 합산 기준)
- (v1.7) 엑셀 불러오기 카드사별 양식 보강: 금액은 칸 이름에 "원금"이 있으면 그 칸(할인·포인트를 뺀 이번 달 실제 결제 금액, 할부는 이번 회차 금액)을 씀. 할부는 회차·개월 칸으로 가맹점 뒤에 "(할부 n/N)"을 붙여 달마다 따로 저장(같은 파일 다시 불러오기는 중복으로 건너뜀, 날짜는 처음 산 날). 칸 이름이 같은 시트(삼성카드 일시불·할부 등)는 함께 읽고 칸 이름이 다른 시트(롯데 해외이용 상세·선할인 등)는 읽지 않음. 두 줄 칸 이름(우리카드 "당월결제하실금액/원금", 롯데 "이번 달 입금하실 금액/원금")과 HTML 표의 세로 병합 칸 처리. 연회비 줄 제외, 매출구분 "국외"·가맹점 "(USD)"는 해외사용. 날짜에 연도가 없으면(우리카드 03.05) 조회 연도로 정하고 파일 이름의 "N월"보다 뒤 달은 전년도로, 확인 화면에서 연도 변경. 파일 이름에 "현금영수증"이 있으면 현금영수증, "불공제" 표시는 빠짐. 원화·외화가 한 칸에 줄바꿈으로 있으면 원화만 읽음. 실제 파일(삼성 10·롯데 10·우리 7·현금영수증 10개)로 사용자 집계 파일과 건수·금액 일치 확인

## 목업과 실제 기능의 경계
공제현황의 카드 소득공제액은 국세청 2025년 귀속 연말정산 안내(p.28·p.41) 기준으로 실제 계산합니다. 2026년은 같은 기준을 적용하며 2026 개정(자녀 한도 가산 등)은 반영하지 않았습니다. 2027년 이후는 "기준 없음"으로 표시하고 계산하지 않습니다.
사용구분을 공제 제외 항목으로 입력한 내역은 카드 소득공제 계산에서 뺍니다. 직접 입력할 때는 사용처 이름으로 판정하지 않고, 엑셀 불러오기에서만 가맹점 이름으로 사용구분을 제안합니다(확인 화면에서 수정 가능). 나머지 내역은 공제 대상이라고 가정합니다.
엑셀 불러오기: .xlsx와 엑셀 원본 .xls를 읽을 때만 SheetJS 0.18.5를 cdnjs에서 받아오므로 인터넷이 필요합니다(HTML 표 형식 .xls·CSV는 인터넷 없이 읽음). 비밀번호가 걸린 파일은 읽지 못하므로 Excel에서 비밀번호 없이 다시 저장해야 합니다. 실제 카드사 파일로는 아직 검증하지 않았고, 예시 파일(삼성형 xlsx·현대형 HTML xls·KB형 CSV·롯데형 XML 엑셀·우리형 UTF-16 탭 구분)로만 확인했고, 옛 이진 형식 .xls는 예시 파일이 없어 확인하지 못했습니다. 직접 입력한 내역은 불러온 내역과 중복 여부를 비교하지 않으므로 같은 거래를 두 번 넣지 않도록 확인 화면에서 빼야 합니다. 부분취소도 음수 금액 그대로 저장되므로 따로 고치지 않아도 됩니다(짝 표시는 "원거래 없음"으로 나옴).
문화비는 총급여 7천만원 이하일 때만 30%로, 초과하면 결제수단 공제율로 계산합니다. 가족 합산·중도 입·퇴사·환불·중고차는 입력 항목이 없어 계산하지 않습니다.
환급액, 결제수단 추천은 구현하지 않았습니다.
홈의 3,000만원은 임의의 소비 관리 목표이며 법정 기준이 아닙니다.
전통시장/대중교통/문화비 합계는 사용자가 지정한 분류의 합계이며 공제 인정 여부를 판정하지 않습니다.
중복공제 카드는 사용구분별 금액 합계이며 의료비 3% 기준·교복 한도 등 실제 세액공제액은 계산하지 않습니다.
현금영수증 확인 표시는 사용자가 홈택스에서 직접 대조한 뒤 누르는 표시이며 국세청 자료를 자동으로 가져오지 않습니다.
JSON 복원은 합치기 방식입니다: 백업의 내역 중 이 기기에 없는 것(같은 id·같은 importKey가 없는 것)만 추가하고, 기존 내역과 이 기기의 총급여는 그대로 둡니다. 같은 거래를 두 기기에서 각각 직접 입력했다면 id가 달라 둘 다 남습니다.
카드사/홈택스 연결, 서버 저장, 로그인, 기기간 동기화는 없습니다.
브라우저 저장소는 암호화 저장이나 접근 제어를 제공하지 않습니다. 목업 테스트에는 예시 자료를 사용하세요.
